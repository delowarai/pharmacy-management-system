# Pharmacy Management System

Internal pharmacy management and POS application built with FastAPI, React, Tailwind CSS and PostgreSQL.

## Projects

- `backend/` — FastAPI REST API, authentication, inventory, purchases, sales, parties, expenses and reports.
- `frontend/` — Responsive React/Vite dashboard and POS interface for desktop, tablet and mobile browsers.

## Local development

Read [`backend/README.md`](backend/README.md) and [`frontend/README.md`](frontend/README.md). Never commit `.env` files or production credentials.

See [`PROJECT_STRUCTURE.md`](PROJECT_STRUCTURE.md) for the complete PyCharm/WebStorm folder map.

## Deployment

- Backend and PostgreSQL: Render or a private Docker server.
- Frontend: Vercel, static Nginx, or another Vite-compatible host.

This system is intended for internal pharmacy operations; it does not include public e-commerce or online medicine delivery.
